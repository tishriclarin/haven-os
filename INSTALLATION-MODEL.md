# Installation model

Status: proposed; not implemented or security-validated.

Start with a documented Debian Stable integration profile; an installer/ISO follows validated runtime integration.

Preflight: supported firmware, Secure Boot, TPM2, storage identity, virtualization/IOMMU needs, backups and recovery destination. Explain compatibility modes and downgraded protections.

Disk layout and boot chain remain proposals. Require explicit human approval for destructive partitioning. Secure completion requires verified encryption, independently tested recovery, signed update configuration and clear status reporting.
