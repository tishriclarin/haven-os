# Security policy
No supported release or production security guarantees exist. Do not deploy this planning repository as a hardened OS.

Report non-sensitive design questions in issues. For exploitable weaknesses, use GitHub's private vulnerability reporting if available in the Security tab. A dedicated reporting channel and response SLA have not yet been established; do not post secrets or exploit details publicly. If no private route is available, request a private reporting channel without disclosing details.

Before a supported release, maintainers must establish and test confidential reporting, triage ownership, coordinated disclosure, supported versions and response targets.
