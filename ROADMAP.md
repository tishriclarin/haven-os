# Roadmap
| Milestone | Deliverable | Release gate |
|---|---|---|
| M1 Foundation | Reviewed architecture and governance | Threat/trust review; critical questions resolved |
| M2 Document MVP | Guard, launcher, document broker, trusted UI, demo editor | Positive and negative capability tests |
| M3 Policy integration | Sensors, devices, network, history, VM profiles | Isolation and crash/recovery evidence |
| M4 System prototype | Boot/storage, signed updates, installer, ISO | Recovery, rollback, signature and install tests |
| M5 Candidate release | Documented hardware/support matrix | External review and release checklist |

No dates or production promises are assigned. Work proceeds by evidence and maintainer review.
