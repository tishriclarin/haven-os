# AI rules
1. Do not grant broad host filesystem access to fix compatibility.
2. Do not substitute persistent directories for user-mediated file capabilities.
3. Never let an untrusted app mint trusted interaction evidence.
4. Keep risky development inside VMs; do not weaken host isolation.
5. Never commit/log/export raw recovery material; exports must be encrypted.
6. Security downgrades require explicit scope and visible state.
7. Deny unauthorized grants; document safe recovery behavior.
8. Background requests confer no new authority.
9. Keep trusted services minimal; no arbitrary command execution API.
10. Record trust-boundary changes and test negative paths.
11. Distinguish plans from tested implementation and guarantees.
12. Do not include private personal information in public project files.
13. State revocation limits for open descriptors and copied data.
14. Preserve existing work and upstream licenses.
