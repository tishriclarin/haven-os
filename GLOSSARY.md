# Glossary
| Term | Meaning |
|---|---|
| Authority | Legitimate basis to perform an operation |
| Capability | Narrow authority bound to subject, resource and action |
| Broker | Trusted service mediating resource operations |
| Portal | User-facing/session interface to a broker |
| Guard | Haven system policy service |
| Trusted interaction | User action evidenced by a trusted input/UI path |
| TCB | Components whose compromise defeats stated guarantees |
| Measured boot | Recording boot component measurements |
| Secure Boot | Signature-based boot authorization |
| Attestation | Verifiable statement about measured state |
| Revocation | Stopping future authority, with documented limits |
| Compartment | Isolated workload environment |
