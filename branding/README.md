# Haven OS identity

The user-supplied PNG boards replace the initial repository SVG identity.

| Asset | Use | Original |
|---|---|---|
| [Shield/H identity board](identity/haven-shield-h-board.png) | Primary presentation, README; “A safer place to build” | 6652.png |
| [Harbor identity board](identity/haven-harbor-board.png) | Retained alternative; “A safer tomorrow together” | 6656.png |

Both boards are preserved byte-for-byte. Each includes a main logo, app icon and one-color variant. These are reference sheets, not isolated production icon exports or editable vector masters. No automatic tracing, cropping or recoloring has been performed.

The user designated the supplied artwork as the project logo. Since two designs were supplied without an ordering preference, shield/H is the current primary presentation and harbor is retained as an alternative.
