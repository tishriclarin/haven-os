# Governance
Tishri Clarin (@tishriclarin) is the initial maintainer. Maintainers approve architecture, releases and repository access.

Public viewing and forking are welcome. Direct pushes and merges are restricted to the owner and explicitly authorized write collaborators. Contributor attribution does not grant access. Outside contributions use pull requests.

Prefer reviewed pull requests for all ongoing work. Security-sensitive changes need documented threat analysis and reviewer evidence. Branch protection/rulesets should be configured separately; this document is policy, not proof of a GitHub setting.

No contributor invitations are sent by this foundation change. Grant the minimum role explicitly requested. Track significant decisions in DECISIONS.md; resolve disputes through reasoned maintainer review.
