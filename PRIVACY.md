# Privacy

Status: proposed; not implemented or security-validated.

No telemetry is planned by default. Any future diagnostics require documented fields, destination, retention, purpose and explicit choice.

Local audit records are sensitive: omit file contents, secrets, capability tokens and packet payloads; minimize filenames and destinations; bound retention and access. Users can inspect privacy history and retention settings.

State what the OS can actually observe. No absolute claim of no observation or surveillance detection is possible. Threat-model limits remain visible. This repository contains public project information, not private founder records or credentials.
