# Contributing
Read README.md, PLANS.md, THREAT-MODEL.md, TRUST-MODEL.md, AGENTS.md and AI_RULES.md first.

Open an issue defining the problem, boundaries, acceptance criteria and risks. Use a branch and pull request; explain behavior, validation and remaining limits. Do not commit credentials, private records, recovery keys or sensitive logs.

Phase 1 accepts architecture and test specifications. New production code requires an approved design. Compatibility fixes cannot silently broaden grants. Changes to trust boundaries require an ADR and negative test cases.

Contributions use the repository MIT license unless an existing file states otherwise. Preserve upstream licensing. AI assistance must receive human review; authors remain responsible for correctness.

Only explicitly authorized collaborators can push/merge. Anyone can propose a fork/PR. Security reports follow SECURITY.md.
