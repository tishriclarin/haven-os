# Hardware requirements

Status: proposed; not implemented or security-validated.

Initial target: x86-64 Debian Stable desktop with UEFI, TPM2 and Secure Boot for the secure profile; hardware virtualization for VM profiles. IOMMU is required for passthrough, with usable device groups and reset behavior.

Provisional development budget: 16 GB RAM minimum, 32 GB preferred; SSD capacity sized for multiple VM images and snapshots. These are planning estimates, not a certified compatibility matrix.

List tested models, firmware versions, devices, suspend behavior, secure boot path and recovery results before release. Unsupported hardware must show unavailable protections instead of success indicators.
